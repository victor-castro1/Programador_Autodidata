# Programador Autodidata

Repositório criado para registrar minha jornada de aprendizagem em programação
a partir do livro **Programador Autodidata**, de Cory Althoff.

Aqui reuno:
- Anotações Próprias;
- exemplos de código;
- exercícios, desafios e projetos;


> Este repositório é um portfólio, 
> Os códigos mostram minha evolução como um todo

## Objetivos

- Praticar Python por meio de exercícios e desafios;
- Documentar o que aprendo com minhas próprias palavras;
- Conseguir terminar o livro.

## Como executar os exemplos

Clone o repositório:

```bash
git clone https://github.com/victor-castro1/Programador_Autodidata.git
cd Programador_Autodidata
```

Depois, execute um arquivo de sua preferência em Python:

```bash
python capitulo-01/exemplos/hello_world.py
```
